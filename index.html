Денежные события

G — сумма оплат sale в периоде.
R — сумма refund в периоде, в том числе по старым заказам.
N = G − R. Это денежный поток по событиям, не бухгалтерская прибыль.

Средний оплаченный чек = G / O, где O — число разных оплаченных заказов в периоде. Возврат не уменьшает исходный чек. При O = 0 средний чек отсутствует.

Клиенты и дата отсечения

Из заказов с оплатой в периоде оставляем те, у которых остаток после возвратов до конца периода больше нуля (E). C — число их клиентов. C₂ — клиенты с двумя и более разными такими заказами.

Доля повторных = C₂ / C. Полный возврат исключает заказ из этой метрики. Это повторные клиенты внутри периода, в выбранной валюте; ранние покупки не добавляются в числитель.

Форматы, ограничения и обработка ошибок

Обязательные поля: event_id, order_id, customer_id, date, type, amount, currency. В режиме частей нужен line_id. Типы: только sale/refund/cancel. Оплаты и возвраты положительные, отмена — явно 0. Отмена означает неоплаченный заказ.

Даты только YYYY-MM-DD (или датированные ячейки Excel без времени, системы 1900/1904). Timestamp и неоднозначные даты отклоняются. Период включает обе даты; зона отчёта Europe/Moscow, дневные границы без времени.

Валюты RUB, USD, EUR с двумя десятичными знаками. Деньги суммируются целыми копейками/центами. Дроби точнее 0.01 отклоняются. Средний чек и проценты округляются half-up только при выводе. Валюты не складываются.

Возврат требует исходную оплату в загруженной истории, того же клиента и валюту, дату не раньше оплаты и сумму всех возвратов не выше оплаты. Несколько оплат одного заказа, sale + cancel и рассрочки не поддерживаются.

Точные дубли ключа удаляются с предупреждением; разные значения одного ключа — ошибка. Части объединяются только при одинаковых общих полях. Ошибка блокирует весь новый импорт; прежний отчёт сохраняется. Частичных отчётов нет.

CSV: UTF-8, явный разделитель, корректные кавычки. XLSX: выбор листа и строки заголовка; ID должны храниться текстом. Макросы и формулы не исполняются, формулы в сопоставленных полях отклоняются. Пустое поле не превращается в ноль.
